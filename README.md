# Gửi vợ yêu · 20/10

A Vietnamese Women's Day greeting for my wife, inspired by the supplied Pepe illustration.

## View

Open `index.html` directly in a modern browser. The illustration is embedded; no installation, build, external font, analytics, or API is required.

The page includes a native expandable letter, a flower dialog with keyboard dismissal, responsive layouts, and support for reduced motion.

## GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, select **master** and **/(root)**, then **Save**. The page is intended for the root of this repository's Pages site. GitHub will show the published address when deployment completes.

Source privacy and Pages availability depend on the GitHub account plan. This repository's visibility should only be changed by its owner.

## Edit

All text, CSS, image data, and JavaScript are in `index.html`. Edit the letter and signature there.

## Validation

HTML links, IDs, embedded illustration, offline asset references, and JavaScript syntax were checked. Browser layout and live deployment still require verification.
